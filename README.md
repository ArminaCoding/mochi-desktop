# Mochi 桌宠

小小陪伴，刚刚好。Mochi 是一款 Windows 桌面陪伴软件，支持多位伙伴、自定义皮肤、日常互动与桌面工具。

## 使用说明

**[📖 点击查看《Mochi 桌面版使用说明书》（飞书在线版）](https://my.feishu.cn/wiki/IRawwwYdliuWQNkAQIxcgnnlnMb)**

无需登录飞书即可阅读，获得链接的人可查看，未开放编辑权限。说明书包含安装与免安装版区别、伙伴管理、皮肤导入、悬停动作环、性能模式、模型配置、局域网串门、授权与数据备份等 13 个章节。

手册适用于 **0.5.40**。请先核对软件左下角版本号：下载页可能保留较早安装包；文档更新不代表安装包已同步更新。动作环与拖入导入需要 0.5.40 或更新版本。

## 下载

前往 [Releases 下载页面](https://github.com/ArminaCoding/mochi-desktop/releases/latest)，选择需要的版本和文件：

| 文件 | 用途 |
| --- | --- |
| `Mochi-Setup-版本号.exe` | 安装版，适合长期使用。 |
| `Mochi-Portable-版本号.exe` | 免安装版，放入固定文件夹后运行。 |

关闭管理中心后软件仍可能在系统托盘运行，完全退出请使用托盘菜单的「退出 Mochi」。升级或迁移前，建议先在偏好设置中备份数据。
